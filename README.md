# FollyStars Bot

## Встановлення
Потрібен Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

Скопіюйте `.env.example` у `.env` та заповніть:
- `BOT_TOKEN` — токен від @BotFather
- `ADMIN_ID` — ваш Telegram numeric user ID
- `REVIEW_CHANNEL_ID` — канал для публікації відгуків (наприклад, `@mychannel`); додайте бота адміністратором каналу з правом публікації
- `REVIEWS_URL` — посилання на канал відгуків
- `CARD_NUMBER`, `CARD_OWNER` — платіжні реквізити, які показуються покупцю
- `DB_PATH` — шлях до SQLite бази (необов'язково)

Запуск:
```bash
python bot.py
```

## Реалізовано
- Вибір отримувача: друг або собі
- Введення та перевірка @username
- Кнопки 50/100/200/500 і власна кількість від 50 до 100000
- Розрахунок за курсом 0.78 грн за зірку
- Створення замовлення та унікального ID
- Показ банківських реквізитів та прийом фото чека
- Передача чека адміністратору з кнопками схвалення/відхилення
- Після схвалення — повідомлення покупцю
- Після фактичної доставки адміністратор виконує `/done ORDER_ID`
- Після `/done` покупець може залишити відгук з фото (необов'язково), текстом та оцінкою 1–5
- Публікація відгуку в `REVIEW_CHANNEL_ID`, якщо змінну налаштовано
- Міграція старої SQLite таблиці orders без видалення існуючих замовлень

## Важливо
- Автоматичної доставки Stars через Fragment тут немає: адміністратор має доставити їх вручну, а потім виконати `/done ORDER_ID`.
- Перед запуском перевірте актуальні правила Telegram щодо продажу цифрових товарів у ботах. Telegram вимагає використовувати Telegram Stars (XTR) для цифрових товарів, що продаються всередині ботів; оплата банківським переказом у такому сценарії може не відповідати правилам платформи.
- Не публікуйте токен бота та не надсилайте його нікому.
